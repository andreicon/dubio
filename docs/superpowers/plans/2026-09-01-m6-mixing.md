# Milestone 6 — Mixing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Separate the original audio into dialogue/music/SFX stems, then build the final mix by placing each processed dialogue clip at its original start time on a dedicated dialogue layer and combining it with the preserved music + SFX, writing `mix/final.wav`.

**Architecture:** A `SourceSeparator` interface (fake + Demucs) produces `audio/{dialogue,music,sfx}.wav`, with graceful fallback to original audio if separation is weak (PRD §9). `pipeline/mix.py` composes a timeline: dialogue clips are placed at `original_start` (never moved, PRD §20), summed into a dialogue bus, then mixed with music+SFX using per-track/per-character/per-utterance gain, pan, fades, and optional ducking.

**Tech Stack:** Demucs, numpy, soundfile, existing manifest/measure modules.

**Spec:** `PRD.md` (§9 audio separation, §20 timing strategy, §24 audio mixing).

## Global Constraints

(See master plan.) M6 focus: preserve original music/SFX; dialogue occupies its own layer; compositor never silently moves dialogue — if a clip cannot fit, mark the utterance failed; separation engine replaceable with original-audio fallback.

**Consumes:** M1 `Manifest/Utterance/ProjectPaths`, `audio/source.wav`, `timing`; M4 `audio/processed/<utt>.wav`; M0 `measure`/`process.gain_db`.

        return separator.separate(src, paths.audio_dir)

            raise DubError("SEP-001", f"Separation failed: {e}", {"source": str(src)})

- [ ] **Step 3: Implement `pipeline/mix.py`**

```python
import numpy as np
from dubio.audio.measure import load_wav, write_wav
from dubio.audio.process import gain_db
from dubio.project.manifest import Manifest
from dubio.errors import DubError

def place_clip(bus, clip, start_s, sr, fit=True):
    start = int(start_s * sr)
    end = start + len(clip)
    if end > len(bus):
        if not fit:
            raise DubError("MIX-001", "Clip overruns available interval",
                           {"start_s": start_s})
        clip = clip[: len(bus) - start]
        end = len(bus)
    bus = bus.copy()
    bus[start:end] += clip
    return bus

def build_dialogue_bus(m, paths, sr, total_samples):
    bus = np.zeros(total_samples)
    failed = []
    for u in m.utterances:
        processed = paths.processed_dir / f"{u.id}.wav"
        if not processed.exists():
            continue
        clip, csr = load_wav(processed)
        try:
            bus = place_clip(bus, clip, u.source.start, sr, fit=False)
        except DubError:
            u.validation.duration = "fail"
            failed.append(u.id)
            bus = place_clip(bus, clip, u.source.start, sr, fit=True)  # still place, truncated
    return bus, failed

def mix_tracks(dialogue, music, sfx, gains):
    n = max(len(dialogue), len(music), len(sfx))
    def pad(x): return np.pad(x, (0, n - len(x)))
    return (pad(gain_db(dialogue, gains.get("dialogue",0.0)))
            + pad(gain_db(music, gains.get("music",0.0)))
            + pad(gain_db(sfx, gains.get("sfx",0.0))))

def mix_project(paths, config) -> None:
    m = Manifest.load(paths.manifest)
    music, sr = load_wav(paths.audio_dir / "music.wav")
    sfx, _ = load_wav(paths.audio_dir / "sfx.wav")
    total = len(music)
    dialogue, failed = build_dialogue_bus(m, paths, sr, total)
    gains = {"dialogue": 0.0, "music": -6.0, "sfx": -3.0}  # configurable
    final = mix_tracks(dialogue, music, sfx, gains)
    # peak safety
    peak = np.max(np.abs(final)) or 1.0
    if peak > 0.995:
        final = final * (0.995 / peak)
    write_wav(paths.mix_dir / "dialogue.wav", dialogue, sr)
    write_wav(paths.mix_dir / "music.wav", music, sr)
    write_wav(paths.mix_dir / "sfx.wav", sfx, sr)
    write_wav(paths.mix_dir / "final.wav", final, sr)
    if failed:
        from dubio.logging import get_logger
        get_logger("mix").warning("clips_truncated", ids=failed)
    m.save(paths.manifest)
```
